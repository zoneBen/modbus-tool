# Modbus Tool

对标 Modbus Poll 的轻量桌面调试工具：主站读写、从站模拟、原始报文监视、四类设备扫描、实时曲线。支持 RTU / ASCII / MBAP 三种帧格式与串口 / TCP / UDP 三种链路。

## 已实现

- **协议核心**：PDU 编解码、CRC16/LRC、RTU/ASCII/MBAP、异常码、INT8/16/32/64、UINT、FLOAT32/64、HEX/BIN/ASCII、ABCD/DCBA/BADC/CDAB、从站模拟引擎
- **主站引擎**：TCP / UDP / 串口；RTU / ASCII / MBAP；周期轮询、单次读、FC05/06/0F/10 写、读重试、写不自动重试、自动重连、跨事务 ID 校验、t3.5 串口排空
- **定义编辑**：FC01–04、从站 ID、地址/数量、数据类型、字节/字序、轮询周期、启停；保存后即时生效；列表内直接删除定义，别名在列表中双击维护；新建会话不再自动生成 1–16 读取定义
- **会话管理**：新建、启动/停止、参数编辑、切换、关闭删除；运行中保存参数会按新链路重启；串口为默认链路，默认 9600 8N1 / RTU；串口列表从本机自动读取，支持刷新与手动输入端口
- **写入弹窗**：表格按钮打开，支持从站 ID、FC05/06/0F/10 或按定义自动编码、地址与值配置；成功/失败原因（含 Modbus 异常码中文说明）在弹窗与通知中反馈
- **报文监控**：双向原始帧、分段着色 HEX、字段解码、时间戳、延时、搜索/方向过滤/跟随/清空、帧详情；切换会话自动过滤到当前会话，一键导出 CSV
- **手动原始发送**：主界面下方常驻发送栏，支持 ASCII 原样发送与 HEX 字节发送；自动校验输入并反馈发送/接收字节数与延时，收发内容同步记录到报文监控
- **从站模拟器**：TCP（MBAP / RTU / ASCII over TCP）与串口 RTU / ASCII 监听；可设从站 ID；模拟保持/输入寄存器 0–15、线圈/离散输入 0–7，主站读写实时回显；双击数值可按数据类型与端序逆向编码修改模拟值，模拟列表不显示趋势栏
- **四类扫描**：从站 ID、寄存器地址、串口波特率、局域网 IP/端口（CIDR + 并发 + 可选 Modbus 探测）；进度、取消、实时结果
- **实时曲线**：uPlot 多序列、1/5/15/30 分钟窗口、暂停、跨线提示、图例实时值、数据表视图；双击数值/原始值/趋势列进入带返回按钮的全屏趋势大图；读取失败以 `—` 占位并从趋势中剔除，不写入 0
- **界面**：深色仪器风与浅色高对比主题可切换（支持跟随系统），语义化色板/半透明层级、毛玻璃静态面板、值变化闪烁、状态呼吸、可拖拽监控抽屉、快捷键预留、地址基址 0/1；设置内可切换简体中文 / English（预览）
- **列表交互**：双击别名编辑点位名称，双击格式编辑数据类型与字节/字序，双击数值或趋势查看大图
- **浏览器 Demo**：无需 Rust 即可体验完整界面，并在浏览器内生成真实结构的 MBAP/RTU 帧、主站/从站数据、扫描过程与曲线
- **关于页面**：展示作者微信二维码、软硬件全栈定制服务与国产信创适配能力介绍

## 已知限制 / 下一步

- **从站模拟器**：支持 TCP 与串口 RTU/ASCII；暂不支持 UDP；内置映射为 16 个寄存器 / 8 个线圈，支持逐值修改与逆序编码，尚未加入自定义映射容量编辑
- **CSV 数据日志**：UI 入口已预留，写入任务待实现（P6）
- **工作区持久化**：会话/定义当前驻留内存，重启丢失（P4）
- **串口**：已接入本机串口枚举（含 USB-Serial / CH340 等），不同厂商驱动的兼容性按现场设备验证
- **English**：当前为预览，部分新增弹窗仍为中文，后续逐步补全
- **FC08/11/17/22/23/43-14**：后续阶段
- **扫描**：修复了扫描任务在非 Tokio 上下文启动导致进程退出的问题；扫描失败会回传状态与错误信息
