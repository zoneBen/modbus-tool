# Modbus Tool

对标 Modbus Poll 的轻量桌面调试工具：主站读写、从站模拟、原始报文监视、四类设备扫描、实时曲线、点位告警与独立网络助手。支持 RTU / ASCII / MBAP 三种帧格式与串口 / TCP / UDP 三种链路。

## 已实现

- **协议核心**：PDU 编解码、CRC16/LRC、RTU/ASCII/MBAP、异常码、INT8/16/32/64、UINT、FLOAT32/64、HEX/BIN/ASCII、ABCD/DCBA/BADC/CDAB、从站模拟引擎
- **主站引擎**：TCP / UDP / 串口；RTU / ASCII / MBAP；周期轮询、单次读、FC05/06/0F/10 写、读重试、写不自动重试、自动重连、跨事务 ID 校验、t3.5 串口排空
- **定义编辑**：FC01–04、从站 ID、地址/数量、数据类型、字节/字序、轮询周期、启停；保存后即时生效；列表内直接删除定义，别名在列表中双击维护；新建会话不再自动生成 1–16 读取定义
- **点位配置**：每个寄存器可独立设置数据类型、字节/字序、含义、单位、缩放与偏置；显示值按 `原始值 × 缩放 + 偏置` 计算；定义导入/导出完整携带点位、别名、告警与模拟配置
- **告警规则**：每个点位可配置多条条件，包含告警描述、告警等级（提示/警告/严重）、操作符、阈值、持续时间与启用状态；每条规则还可单独配置恢复条件及恢复等待时间：未配置时告警条件消失即恢复，配置后必须同时满足“告警条件消失 + 恢复条件持续成立达到等待时间”才生成恢复记录。支持多选寄存器批量下发规则；告警记录使用独立页面，左侧引用工作区会话列表，点击会话只显示对应告警；记录可导出 CSV
- **会话管理**：新建、启动/停止、参数编辑、切换、关闭删除；运行中保存参数会按新链路重启；串口为默认链路，默认 9600 8N1 / RTU；串口列表从本机自动读取，支持刷新与手动输入端口；波特率可从常用值快速选择或直接输入；连接失败与非法参数会在弹窗内持续提示
- **写入弹窗**：表格按钮打开，支持从站 ID、FC05/06/0F/10 或按定义自动编码、地址与值配置；成功/失败原因（含 Modbus 异常码中文说明）在弹窗与通知中反馈
- **报文监控**：双向原始帧、分段着色 HEX、字段解码、时间戳、延时、搜索/方向过滤/跟随/清空、帧详情；切换会话自动过滤到当前会话，一键导出 CSV
- **原始调试终端**：顶部「调试」打开独立终端（需先停止轮询），持续实时接收链路原始字节，不按 Modbus 帧解析；支持 ASCII / HEX 手动发送、CR/LF 后缀勾选、收发日志、字节统计、清空、自动跟随与日志 CSV 导出，适合非 Modbus 设备调试；接收内容为设备实际返回，可能包含终端回显
- **网络助手**：独立工作台页面，支持多网络会话并行运行；左侧会话列表、右侧参数与收发记录；支持 TCP 服务端、TCP 客户端、UDP 服务端、UDP 客户端与 TCP 中继。新建会话时按模式只显示必需参数：TCP/UDP 客户端仅显示目标地址与端口，服务端仅显示监听参数，中继显示本地监听与上游参数。服务端可接收多个 TCP 客户端并广播发送；日志支持 ASCII/HEX、自动跟随、清空与 CSV 导出；参数自动保存，重启后默认不自动启动
- **从站模拟器**：TCP（MBAP / RTU / ASCII over TCP）与串口 RTU / ASCII 监听；可设从站 ID；新建从站默认是**空白模拟映射**，必须手动新增至少一个寄存器映射后才能启动监听；映射支持新增、编辑（地址/含义/类型/字节序/发生器）与删除；每个寄存器可配置数据类型、字节序、变化方式（固定/递增/递减/随机）、刷新周期、最小/最大值与启动刷新；启动前写入初始值，运行中按配置更新；支持双击修改模拟值与模拟配置导入/导出
- **四类扫描**：从站 ID、寄存器地址、串口波特率、局域网 IP/端口（CIDR + 并发 + 可选 Modbus 探测）；使用独立扫描工作台，左侧保存多个扫描会话，右侧显示进度、取消与扫描结论；多个扫描任务可同时运行，结论可导出 CSV
- **实时曲线**：uPlot 多序列、1/5/15/30 分钟窗口、暂停、跨线提示、图例实时值、数据表视图；双击数值/原始值/趋势列进入带返回按钮的全屏趋势大图，并以该寄存器及相邻寄存器为默认数据源；读取失败以 `—` 占位并从趋势中剔除，不写入 0
- **界面**：工作台、网络助手、设备扫描与告警记录均为全页面切换；深色仪器风与浅色高对比主题可切换（支持跟随系统），语义化色板/半透明层级、毛玻璃静态面板、值变化闪烁、状态呼吸、可拖拽监控抽屉、快捷键预留、地址基址 0/1；全新 M 波形应用图标；左侧功能入口具备选中高亮；设置内可切换简体中文 / English
- **列表交互**：双击别名编辑点位名称，双击格式编辑数据类型与字节/字序，双击数值或趋势查看大图；选中寄存器后定义检查器同步显示该行采样，并列出多种数据类型/端序的解析参考
- **浏览器 Demo**：无需 Rust 即可体验完整界面，并在浏览器内生成真实结构的 MBAP/RTU 帧、主站/从站数据、扫描过程与曲线
- **工作区持久化**：会话、链路参数、读取定义、点位、别名、告警规则与模拟配置自动保存在本机；重新打开应用后恢复上次配置，但所有会话默认保持断开，需要手动点击连接；网络助手与界面偏好同样保留，链路不会自动启动
- **全局配置导入/导出**：左侧栏设置按钮上方提供导入与导出按钮，一次保存或恢复全部软件配置，包括界面偏好、工作区会话、读取定义、点位、别名、告警规则、模拟映射与网络助手会话；导入前二次确认，导入后所有链路保持断开
- **关于页面**：展示作者微信二维码、软硬件全栈定制服务与国产信创适配能力介绍；页面与全部弹窗文本均支持简体中文 / English

## 已知限制 / 下一步

- **从站模拟器**：支持 TCP 与串口 RTU/ASCII；暂不支持 UDP 从站；映射使用稀疏地址（可为每个映射单独设置地址），整个映射的地址跨度不能超过 65535；模拟发生器适合连续变化量与固定值验证
- **CSV 数据日志**：报文、告警、调试与网络日志均已支持导出；按轮询周期持续写入的自动 CSV 记录任务尚未实现
- **原始调试**：调试模式独占当前链路，必须先停止轮询；调试收发流量显示在调试终端中，不写入 Modbus 报文监控
- **网络助手**：与 Modbus 会话完全独立；TCP 中继一次接受一个本地客户端，客户端断开后需重新启动中继
- **串口**：已接入本机串口枚举（含 USB-Serial / CH340 等），不同厂商驱动的兼容性按现场设备验证
- **English**：界面文本（含关于页面与全部弹窗）已完整双语；协议核心/设备返回的错误详情与浏览器演示示例数据暂保留中文
- **FC08/11/17/22/23/43-14**：后续阶段
- **扫描**：修复了扫描任务在非 Tokio 上下文启动导致进程退出的问题；扫描失败会回传状态与错误信息
